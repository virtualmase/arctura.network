Practice 01 of 07

Learn the shape of accountable work

Start with the real question, the evidence available, and the boundary an agent must not cross.

Status: Published educational methodology. Use it as a review pattern, not as evidence that a specific agent or capability has been deployed.

Field practice

Run the practice

  1. 01

    Restate the requester’s actual decision before proposing a solution.

  2. 02

    Separate supplied facts, inferences, and unknowns.

  3. 03

    Identify the source that is authoritative for each important claim.

Keep the proof

A short problem frame with cited sources, named unknowns, and an explicit decision owner.

Connect the record to the precise conditions under which the work was performed. A clean result without its scope and limitations is not reusable evidence.
