Choose the right record

The Readiness Check finds gaps. The Accountability Card describes the agent’s standing boundaries. A Work Order defines one task. An evaluation records what actually happened.

The Media Evidence Desk helps organize a claim and its sources. It does not verify those sources for you. Local drafts stay in the browser where the tool supports storage; avoid using a shared device for sensitive material.
