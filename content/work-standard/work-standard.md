# The Work Standard

How Arctura decides what counts as useful work, and what it takes for that work to be trusted by people and by machines.

This is not a course. It's the standard the network already runs on — written out in full, one part at a time.

---

## The parts

1. **What Counts as Work**
   A contribution is work if it changes something and someone else can check it. Opinions, drafts, and unchecked output are not work yet.

2. **What a Claim Needs**
   Every claim made on the record separates fact from interpretation. A fact is checkable. An interpretation is labeled as one. Nothing is stated as settled that isn't.

3. **One Record Per Thing**
   Every person, tool, and process that acts in the network has exactly one canonical record. No duplicate identities, no conflicting descriptions.

4. **Before an Agent Acts**
   Any agent — human or software — must have its resources, authority, and limits mapped before it acts. If the limits aren't written down, the agent doesn't act.

5. **Proof Over Trust**
   The network doesn't ask to be trusted. It shows the record: who did what, who checked it, and what the result was. Trust is something people decide after looking, not something claimed in advance.

6. **Readable by Machines**
   Records are structured so software can find and parse them correctly. This makes the record easier to find. It does not promise ranking, placement, or preferential retrieval anywhere.

7. **Working With Other Systems**
   When Arctura's agents interact with agents from other systems, roles, capabilities, and handoff points are stated plainly. Interoperating with another system is not the same as trusting it — that's decided separately, on evidence.

8. **Separating What Moves**
   Value, payment, delivery, and dispute are four different states, not one. Each is tracked on its own. A payment clearing does not mean the work was accepted. Delivery does not mean the dispute window is closed.

9. **How Decisions Get Bounded**
   Every decision in the network operates inside a written policy. The Council's five checks — Need, Clarity, Usefulness, Durability, Reversal — apply before any change is accepted. Exceptions are logged, not made quietly.

10. **What Gets Offered**
    An offer states exactly what is provided, exactly who qualifies, and exactly what is not included. No offer implies a result it can't back up.

11. **Finding the Real Question**
    Before work starts, the actual problem is stated in the requester's terms, not the network's terms. Work that solves the wrong problem well is still wrong.

12. **What Counts as Proof**
    Evidence that supports a claim is assembled so it can be independently checked — logs, records, outcomes. A single example is not a guarantee, and is never presented as one.

13. **How Agents Talk**
    When an agent represents the network in conversation, it says what it can do, points to evidence for what it claims, and says plainly when something is outside its authority or unknown.

14. **Handing Off to a Person**
    Some decisions require a person, not an agent. Those handoff points are defined in advance — not discovered mid-conversation — and routed to whoever is actually accountable for that decision.

15. **Keeping the Record True**
    Records go stale. Outcomes get checked again after the fact. When something turns out to be wrong, it's corrected on the record — not quietly edited, not left to rot.

16. **The Whole Path, End to End**
    All fifteen parts connect into one line: a real question, checked work, an honest record, the right handoff, and a record that stays accurate after the fact. This is what "useful work" means at Arctura, spelled out in full.
