A shared process

How it works

Work moves through four clear steps. Each one leaves enough information for the next person to understand what happened.

  1. 1

    Contribute work

    Share useful work with the network.

  2. 2

    Review results

    Reviewers check for quality and correctness.

  3. 3

    Reach agreement

    The network agrees on what should be accepted.

  4. 4

    Keep the record

    The result is stored with enough evidence to inspect later.

Shared decisions

The Council

Proposed changes pass five checks before a vote. The checks ask whether the change is needed, clear, useful, durable, and safe to reverse.

  1. 01Need

    Is there a real reason to make this change?

  2. 02Clarity

    Can people understand what changes and who owns it?

  3. 03Usefulness

    Does this add something the network actually needs?

  4. 04Durability

    Will the decision still make sense later?

  5. 05Reversal

    Can we safely change course if the assumption is wrong?
