Three surfaces. One clear authority map.

Arctura Network, Arctura Observatory, and the Autonomous Resource Management technical reference are related properties with distinct jobs. They are not interchangeable sources, and one surface should not be used to prove another surface’s claims.

Source precedence

Resolve claims in this order.

01 · Current operational status
Arctura Network evidence record

Use for the present testnet/mainnet boundary and named evidence artifacts.

02 · Implementation detail
Public repository

03 · Technical vocabulary
ARM reference

Use for framework definitions and standards context, not run confirmation.

04 · Collective context
Arctura Observatory

Use for identity and archival context, not implementation status.

Conflict rule. Where a contextual or technical surface conflicts with a dated Arctura Network evidence record about current operational state, the dated network record takes precedence. Where a source artifact conflicts with a prose claim, the artifact and its timestamp take precedence.

Canonical wording

A relationship statement that does not blur claims.

Arctura Network is the public operational status surface for the open-source ARM subnet implementation. Arctura Observatory is the collective’s public identity and archive. Autonomous Resource Management is the technical reference framework. The public code repository is the primary source for published implementation details. These properties are related, but they are not alternate names for the same evidence source.

This statement is replicated in llms.txt, the authority JSON record, and the site navigation. The source-linked Netuid 505 technical documentation applies this precedence to the local-testnet launch record. The canonical public host is https://arctura.network/.
