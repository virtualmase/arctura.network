Community guidance · ARCTURA-COM-01

Contribute to the work. Do not infer access.

Arctura Base is open source. Community participation begins with the published repository, its tests, and its issue tracker. The current public operator path concerns the documented local Bittensor testnet launch on netuid 505; it is not an invitation to a Finney validator program, staking program, or emissions program.

Repository: arctura-base-subnetCurrent network scope: local testnet · 505Mainnet enrollment: not published

Grow through verified use

One network. Two contribution lanes.

Arctura grows when a useful artifact is created, tested, evaluated, and improved in public. Product contributors work on the Work Standard and Work Order format; subnet contributors work from the separate implementation repository and its testnet boundaries.

Use
Create a Work Order

Turn a real agent job into a portable, bounded contract without uploading its contents.

Evaluate
Share a privacy-safe result

Report which checks passed, which boundary held, and what should change next.

Improve the standard
Propose a bounded revision

Name the real use case, failed or missing check, smallest change, and compatibility impact.

Build the subnet
Work from implementation evidence

Use the subnet repository for code, tests, operational issues, and testnet runbooks.

Choose the right path

Three ways to participate responsibly.

Code contributor
Repository first

Fork the public repository, work from an issue, add tests, pass the stated verification checks, and open a reviewable pull request.

Testnet operator
Bounded local run

Use the documented Bittensor testnet and netuid 505 procedure. Keep the run separate from any claim about Finney or emissions.

Observer
Follow records

Read the launch record, evidence status, and public update. Report documentation conflicts through the repository issue tracker.

Not currently offered
Finney enrollment

No public Finney netuid, validator enrollment, stake instruction, or emissions availability is published on this site.

Where to engage

Use a public, traceable channel.

Open technical work belongs in the repository. Start with the issue tracker, then submit a pull request against the documented process. The contribution guide also lists the public Bittensor and Base builder channels, the project account, and a direct council mailbox.[1]

Related records: Read the Netuid 505 launch record before operating a test run, the evidence status before repeating a claim, and the public launch note for the concise community summary.
