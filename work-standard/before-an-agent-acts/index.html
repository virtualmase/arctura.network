Before an Agent Acts

No agent acts without its resources, authority, and limits mapped first. Arctura's rule for keeping autonomous agents inside their bounds.

Status: Published methodology, version 0.1. This defines a review standard; it does not claim every described capability is deployed.

Home / The Work Standard / Before an Agent Acts

Any agent — human or software — must have its resources, authority, and limits mapped before it acts. If the limits aren't written down, the agent doesn't act.

What has to be mapped first

  1. Resources. What the agent can actually use — compute, funds, data, tools. Stated as a specific list, not "whatever it needs."
  2. Authority. What decisions the agent is allowed to make on its own, and which ones require sign-off from a person. See Authority for how this is recorded at the network level.
  3. Limits. The explicit boundary of what the agent cannot do, even if it's technically capable. A spending cap, a rate limit, a category of decision it must escalate.
  4. Exceptions. What happens when the agent hits a situation the mapping didn't anticipate. The default is: stop and escalate, not improvise.

The rule

No mapping, no action. This isn't a formality — an agent operating without a written boundary is the single most common way a network loses control of its own record. The mapping has to exist and be checkable before the agent's first action, not written retroactively to explain what it already did.

Why this matters

Software agents will do exactly what they're authorized to do, at whatever speed they're capable of. A mapping mistake made by a person gets caught in the next conversation. A mapping mistake given to an agent gets executed immediately and repeatedly. The cost of skipping this step scales with how capable the agent is.

How it connects

This proposed method uses the same five review checks described by Arctura — an agent's resource and authority mapping is itself a proposal, and goes through Need, Clarity, Usefulness, Durability, and Reversal before it's approved.
