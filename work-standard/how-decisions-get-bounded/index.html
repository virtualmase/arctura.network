How Decisions Get Bounded

A five-question review framework for testing whether a proposed change is needed, clear, useful, durable, and safely reversible.

Status: Published methodology, version 0.1. This defines a review standard; it does not claim every described capability is deployed.

Home / The Work Standard / How Decisions Get Bounded

Arctura proposes five checks for reviewing a change: Need, Clarity, Usefulness, Durability, and Reversal. Where this framework is used, exceptions should be recorded rather than made quietly.

The five checks, applied

  1. Need — Is there a real reason for this decision, or is it happening because it's easy to make?
  2. Clarity — Can someone outside the room understand what changed and who's responsible for it?
  3. Usefulness — Does this actually serve the network, or does it just serve whoever proposed it?
  4. Durability — Will this decision still make sense in six months, or is it a fix for a problem that's about to change shape?
  5. Reversal — If this turns out to be wrong, can it be undone without breaking something else?

A decision that fails any one of these doesn't pass, regardless of how strong the other four are.

What happens when there isn't time for the full process

Some situations require a fast call — an active incident, a security issue. When that happens, the person or agent making the call still has to log what decision was made, why the full process was skipped, and who's accountable for the call. That log is reviewed after the fact against the same five checks. Skipping the checks in the moment doesn't mean skipping accountability for the outcome.

What this rules out

  • Decisions with no written policy behind them. If nobody can point to what allowed a decision to be made, it doesn't stand, even if it turned out fine.
  • Quiet exceptions. An exception that isn't logged is indistinguishable from a violation, and gets treated as one until proven otherwise.

Why this matters

Bounded decisions are what make a network's growth predictable instead of chaotic. Without this, every new decision has to be argued from scratch, and precedent means nothing.

How it connects

This is the operating detail behind the authority record as described on the main site — the five checks are the intended review test for future proposals.
