Agent Work Order v1.

A small, portable contract for defining what an agent should produce, which inputs and actions are allowed, how another person can check the result, and when human review is required.

Status: testedPublished: 30 August 2026Schema: JSON Schema

Use it

From intent to a checkable artifact.

01 · Define
Build a Work Order

Use the local-only browser builder. Its contents are not uploaded or retained by Arctura.

02 · Validate
Check the contract

Validate the exported JSON against the published v1 schema or repository validator.

03 · Run
Inspect an example

Start with a synthetic support-review job whose authority and acceptance checks are explicit.

04 · Evaluate
Record the result

Keep a privacy-safe record of checks, boundary compliance, evidence, decision, and limitations.

Reproduce

One command, one result.

Validation command. Clone the repository, install its locked dependencies with npm ci, then run npm run validate:work-order -- examples/work-orders/support-response-review.json. The expected result is Valid Arctura work order: awo-support-response-review-v1.

What comes next

Use must earn the next version.

Version 1 remains stable while representative examples and evaluation cases are collected. Proposed changes should identify a real user, a failed or missing check, the smallest contract change needed, and compatibility impact. No hosted execution service, certification, payment rail, or production-agent guarantee is included in this release.
