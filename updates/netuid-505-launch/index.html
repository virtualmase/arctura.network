Public note · 2026-08-19

Netuid 505 is now documented in public.

Arctura Network has published the source-linked record for Arctura Base’s local Bittensor testnet launch on netuid 505. The announcement is deliberately narrow: it states the documented launch and bounded run, then names the results that are not yet published.

Scope: local Bittensor testnetNetuid: 505Finney: no netuid published

What the record establishes

A real testnet launch, with a bounded result.

The primary implementation repository records Arctura Base operating on the Bittensor test network with netuid 505. Its bounded-run record reports a miner reaching live state, a validator entering its live loop, and mandate issuance.[1] The source is public, inspectable, and linked from the launch record.

Published
Local testnet launch

The network and netuid are documented in the primary run plan.

Published
Bounded startup record

Miner live state, validator live loop, and mandate issuance are reported.

Not claimed
Sustained concurrent results

The bounded run does not report concurrent miner response, non-zero scoring, or sustained weights.

Not claimed
Finney mainnet

No Finney netuid, emissions state, validator enrollment, or mainnet availability is published.

What comes next

More artifacts, not louder claims.

The next useful public addition is an independently checkable run artifact: a UTC-bounded concurrent miner-and-validator result, the stated network and netuid, a metagraph or explorer reference where available, and an immutable log or artifact hash. Until that exists, the current statement remains exactly the documented local-testnet scope.

Community note. Contributors can work through the public repository and issue tracker. Testnet operators should follow the bounded Netuid 505 path. No part of this update asks for funds, stake, wallet material, or Finney-mainnet action.
