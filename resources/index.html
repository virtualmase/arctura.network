Read before you act

  1. Identify which source owns the claim through the authority record.
  2. Validate structure against the schema named in the record.
  3. Keep dates, source URLs, status, and limitations in summaries.
  4. Distinguish an illustrative example from an observed result.
  5. Obtain authorization from the responsible owner before any external action.

This resource index is discovery metadata, not an execution API or a grant of permission.
