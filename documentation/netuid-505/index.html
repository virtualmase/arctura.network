Netuid 505: the local testnet launch record.

Arctura Base was launched and exercised as a local Bittensor testnet subnet on netuid 505. This page records the primary sources, the documented bounded run, and the limits that prevent a local-testnet record from becoming a claim about unrecorded outcomes or Finney mainnet.

Status statement

The claim in one sentence

Arctura Base is a genuine, documented local Bittensor testnet subnet launch on netuid 505. The primary repository records a bounded miner-and-validator exercise, not a hypothetical configuration. It does not publish an active Finney netuid, emissions state, external metagraph receipt, or a sustained concurrent end-to-end run artifact.[1] [2]

Why “local testnet” matters. The published source records use the Bittensor test network and netuid 505. The documentation keeps that exact scope: it is real operational work on the stated testnet, but it is not a substitute for an external historical chain receipt or a Finney-mainnet launch record.
