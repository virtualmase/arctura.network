03 · Stewardship

Convert inspection into checkable use.

Measure
Establish a site baseline

Enable privacy-respecting aggregate analytics at the Cloudflare edge after DNS activation. Do not collect Work Order contents.

Evaluate
Use the evaluation template

Record whether a Work Order produced its expected result and which checks passed or failed, then share a privacy-safe evaluation.

Contribute
Turn a clone into a review

Open an issue, propose an anonymized example, or submit a bounded improvement with verification.

Report
Publish September's delta

Compare the same signals, include site usage when available, and report failures alongside gains.
