Network

What is Arctura Network?

Arctura publishes a practical standard, tools, and evidence for accountable work between people and software. Its central product today is the local-first Agent Work Order builder; its public records show what has been tested and what remains unknown.

Is Arctura live?

Arctura Base has a documented local Bittensor testnet launch on netuid 505. No Finney mainnet netuid, public staking path, emissions state, or live quorum feed is published. Read the evidence record.

What purpose does the testnet serve?

It is implementation evidence: published code and a bounded run showing that part of the approach was exercised under named conditions. It does not prove adoption, production readiness, economic activity, or future mainnet availability.

Work and proof

What does “useful work” mean?

A contribution that produces a defined change and can be checked by another person or process. The Work Standard explains the method.

What is an Agent Work Order?

A JSON record defining the expected result, approved and excluded inputs, allowed actions, acceptance checks, evidence, owner, and human-review boundary before an agent acts. It improves reviewability; it does not certify an agent or guarantee a result.

Who checks the work?

The responsible reviewer named by the work’s actual context. Arctura does not claim a universal validator body for every Work Order. Use the evaluation template to record a result.

Is the Work Standard operational?

It is a published methodology, version 0.1. Individual capabilities are operational only where a linked implementation or dated evidence record says they are.

Participation

How can I take part?

Create and evaluate a Work Order, propose a privacy-safe example, review evidence, open an issue, or follow the documented local-testnet guidance. Start with the contribution paths.

How do I share a result?

Remove credentials, customer data, private prompts, personal information, and confidential outputs. Then use the structured evaluation form.

Who runs Arctura?

Arctura Network owns its public status and evidence claims. The implementation repository is authoritative for code and runbooks. ARM Agency is the delegated website DevOps provider; the authority record defines these roles.

Boundaries

Is Arctura decentralized, a DAO, or an investment?

No active DAO, token offer, investment, payment rail, treasury mechanism, or staking program is represented here. The five checks are a proposed decision framework, not evidence of elected membership or on-chain governance.

Can I lose money here?

Arctura does not offer an investment or public staking path. Running software or test infrastructure can still create costs and technical risk under your own providers. Never treat a testnet record as financial guidance.

What information does the builder collect?

The builder does not upload Work Order contents. If aggregate analytics are activated, only fixed events such as page view, start, copy, and download may be counted—never form answers or exported JSON.
